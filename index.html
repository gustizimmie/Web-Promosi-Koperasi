Pertanyaan Umum (FAQ)

Pertanyaan yang paling sering ditanyakan oleh pelanggan kami

Layanan Koperasi

Apakah sistem mendukung perhitungan bunga simpanan pinjaman otomatis?

Ya, sistem koperasiku mendukung perhitungan bunga simpanan (bulanan/harian) dan pinjaman (flat/efektif/anuitas) secara otomatis sesuai parameter yang ditentukan pengurus.

Apakah ada biaya bulanan untuk Paket Lisensi?

Tidak ada biaya bulanan wajib. Paket Lisensi adalah sistem "Sekali Bayar" untuk lisensi selamanya. Layanan Support/Kendala diberikan secara gratis selama 18 bulan pertama. Setelah masa tersebut berakhir, biayanya hanya Rp 50.000 per bulan untuk support sistem jika Anda membutuhkan bantuan teknis.

Apakah aplikasi bisa berjalan tanpa koneksi internet?

Ya, aplikasi Lisensi Offline/LAN menggunakan Sistem Hybrid. Operasional harian berjalan 100% secara lokal tanpa internet. Internet hanya dibutuhkan saat aktivasi awal atau jika Anda mengaktifkan sinkronisasi Cloud untuk monitoring HP dan backup otomatis.

Apa perbedaan Paket Lisensi dan Paket Full Cloud?

Paket Lisensi (Offline/LAN) bersifat Sekali Bayar dengan penyimpanan data di server lokal (Hybrid). Paket Full Cloud (CMS Koperasi) menggunakan sistem Sewa Bulanan yang 100% berbasis web untuk akses fleksibel dari mana saja tanpa instalasi.
